# Uložené české rozbory – 22. října 2026

Publikační balíček obsahuje 10 105 z 11 264 PDF stran (89,71 %) a souhrny 262 z 267 PDF. Zbývá 1 159 stran a pět souborových souhrnů. Neúplné rozbory lze číst a web je výslovně označuje jako rozpracované; video snímky jsou označené jako vzorek. U kompletních souborů může být část zdroje nečitelná: 3 765 PDF stran nese příznak částečné čitelnosti. Jde o strojové zpracování bez úplné lidské odborné revize.

Všech 447 katalogových záznamů má český popis vydavatele a propojení na originál, včetně 72 záznamů Release06. Originální média se nepřenášejí na tento web. Český katalogový popis je samostatný pramen; není automaticky důkazem obsahu konkrétní stránky. Mapa využívá pouze orientační středy zemí, nikoli doložené souřadnice událostí.

Strukturální audit nemá chyby a zachovává jedno upozornění na fotografickou stranu bez čitelného textu. Kontrola nezaručuje věcnou a jazykovou správnost všech textů. Audit a export fungují bez placených API volání; hotové výsledky se při této publikaci znovu negenerovaly. API překlady jsou pozastavené po poslední schválené etapě; publikace žádná placená volání nespouští.

Reprodukce lokálně s existující databází: python -X utf8 backend/measure_full_pdf.py; python -X utf8 backend/audit_pdf_results.py; python -X utf8 backend/export_source_catalog.py. Ve veřejném repozitáři není místní SQLite databáze, klíče ani originální archiv. JSON v frontend/public/research obsahuje pouze uložené české výsledky a odkazy na prameny.
