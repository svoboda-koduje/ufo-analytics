# Český katalog a původní zdroje – 24. 9. 2026

Nová webová stránka `/badatelna` zpřístupňuje 447 katalogových záznamů všech šesti várek. Release 06 má 72 záznamů. Všechny mají český strojový překlad původního popisu vydavatele a odkaz otevírající konkrétní detail na war.gov. U PDF je navíc přímý odkaz na původní dokument. Velká média se do veřejného webu nekopírují.

## Rozlišení pramenů

Český katalogový popis je překlad tvrzení vydavatele, nikoli nezávislý závěr nebo překlad celého dokumentu. Podrobné české rozbory jsou zatím připravené pro osm souborů (47 stran, obrázků či videosnímků). Zobrazení a filtrování uložených výsledků neprovádí API volání. Videa se v dosavadních rozborech hodnotí jen po vybraných snímcích, bez zvuku a kompletní pohybové analýzy.

Katalogové datum může být datem smlouvy, studie či jiného dokumentu; není vždy datem pozorování. Strojově odhadnutý význam data lze filtrovat. Časový filtr používá pouze doložené události z hotových rozborů. Časová pásma se zatím nepřevádějí. Časová osa zobrazuje katalogové roky a uvádí počet záznamů bez známého roku.

Mapa zobrazuje orientační středy jednoznačně přiřazených zemí u záznamů pozorování. Nejde o souřadnice incidentů. Neznámé, vícenásobné nebo nepokryté lokality se nezobrazují; zůstávají v seznamu. Původní mapový komponent již neposouvá překrývající se body a jeho popisky nevkládají neověřený HTML obsah.

## Zdroje a párování

- Veřejný katalog: https://www.war.gov/Portals/1/Interactive/2026/UFO/uap-data.csv?release=6v3
- Záznamy šesté várky: https://www.war.gov/UFO/release/06/?release=06
- Metadata videí pocházejí z veřejných stránek DVIDS; spojují katalogový video identifikátor s názvem DOD místního souboru. Jejich kopie je v `backend/source_video_metadata.json`.
- `backend/source_catalog.json` je pracovní katalog včetně původu, překladu a párování. `frontend/app/source_catalog.json` je publikovatelný export. `file_to_asset_mapping.json` v backendu a frontendu zůstává kompatibilní se starším formátem a nově má stabilní `source_id` a přímý `source_url`.
- Párování nepoužívá pořadové číslo. Rozlišuje PDF od videa, které může odkazovat na související PDF. Nejednoznačnou shodu odmítá. Ověřeno párování 447 místních souborů a 447 katalogových záznamů, bez nespárovaného záznamu šesté várky.

Pozor na nesrovnalosti přímo u vydavatele: názvy FBI Serial 003/004/005 mají odkazy na odlišně očíslované soubory. U FBI-UAP-D022 se rok v katalogovém názvu liší od roku v názvu souboru. Zachováváme skutečné odkazy vydavatele, nerozhodujeme o správnosti čísla či roku podle názvu souboru.

## Obnova exportu

Z kořene projektu:

```powershell
python backend/source_catalog.py C:\cesta\k\ulozenemu-katalogu.csv
python backend/translate_catalog.py
python backend/export_source_catalog.py
```

První krok obnovuje párování z CSV; po něm je potřeba provést export, který znovu doplní vazby na videa a hotové rozbory. Překlad je explicitní placená operace; hotové výsledky se používají znovu. V případě nejednoznačného API selhání automaticky neopakovat volání. `translate_catalog.py` používá existující rozpočtovou evidenci v `backend/local_state/archive.sqlite3`, nikoli nový rozpočet.

Aktuální celkový evidovaný náklad je 5,360375 USD včetně předchozího pilotu; původní schválený limit je 20 USD. Konzervativní účetní odhad není fakturou poskytovatele. Kompletní archiv není dosud plně přeložený.

## Ověření a nasazení

32 testů backendu prošlo. Produkční sestavení Next.js s kontrolou TypeScriptu prošlo. V prohlížeči ověřena šestá várka, přímé otevření vládního detailu Tremonton, načítání mapových dlaždic, osm hotových rozborů a časový filtr 13:00–13:20 nad hlášením ze Sýrie.

Frontend používá připravená veřejná JSON data a nepotřebuje API klíč ani novou migraci serverové databáze. Render musí nasadit aktualizovaný frontend, aby se `/badatelna` objevila veřejně. Samotná změna místních souborů veřejný web nezmění. Docker sestavuje pomocí `npm ci` a `npm run build`; verze Next.js a Reactu jsou připnuté k ověřenému sestavení.

Pro další etapu: odborná revize překladů a klasifikace, přesnější doložené lokality, normalizovaný katalog událostí napříč stránkami, postupné úplné překlady PDF a analýza video/audio záznamů v samostatně odhadnutém rozpočtu.
